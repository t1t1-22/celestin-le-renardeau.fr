# Célestin Core — 0.2.0

Extension WordPress dédiée à l'univers de Célestin, hébergée dans le dépôt existant (branche main, dossier `celestin-core/`).

## Installation automatique
Le workflow GitHub déploie uniquement cette extension dans `wp-content/plugins/celestin-core` sur le WordPress du projet et l'active au besoin. Aucun autre plugin, thème, volume ou site n'est modifié.

## Accueil illustré
Mise en page codée spécialement pour la maquette Célestin :
- bandeau d'accueil avec illustration et logo
- navigation personnages, activités, livres, mini-histoires
- nouveautés alimentées par les contenus publiés
- aperçu mini-histoire (une illustration, audio MP3, texte)
- aperçu livre carré en double page
- carte personnage
- Fleuriville et bandeau de bienvenue
- pied de page orange
- adaptation mobile et tablette

## Personnaliser les illustrations
WordPress → **Célestin Core → Apparence du site**.
Importer au préalable les vraies illustrations dans **Médias**.
Les images sont facultatives : un fond décoratif apparaît lorsque la zone n'est pas renseignée.

## Gestion du contenu
Types : Mes petites activités, Les livres, Mini-histoires audio, Fiches personnages et Lieux de Fleuriville.
La case « Afficher dans Les nouveautés » met en avant les publications, sans modifier le code.
Le texte de présentation est éditable dans « Apparence du site ».

## Limites de cette version
L'accueil est fonctionnel et contient une maquette visuelle du livre ouvert. **Le vrai feuilletage PDF, les liens relationnels entre contenus, la synchronisation automatique texte/audio et la carte interactive cliquable ne sont pas encore implémentés.** Ils nécessiteront d'autres évolutions.
